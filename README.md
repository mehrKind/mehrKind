# 🚀 Featured Projects

### 🏋️ AI-Powered Sports Training System

An intelligent platform designed to generate personalized training programs for athletes by combining:

- Athlete profiles
- Sports science knowledge
- RAG systems
- Knowledge graphs
- Large Language Models

The system allows coaches to review, modify, approve, or regenerate AI-generated training programs.

---

### 👁️ Knowledge-Based Visual Question Answering

Researching a query-guided approach to VQA where the system:

**Question → Object Grounding → Relevant Visual Regions → Scene Understanding → Knowledge Reasoning → Answer**

The goal is to make visual reasoning more focused, interpretable, and efficient instead of processing the entire image uniformly.

---

### 🎬 Persian Movie & Series Recommendation Chatbot

An NLP-based conversational recommendation system that understands natural Persian queries such as:

> "I'm tired tonight, suggest something light and relaxing."

The system combines:

- User preference extraction
- Hard filtering
- Semantic embeddings
- Cosine similarity
- Hybrid recommendation
- Large Language Models

---

### 🤰 Mom Fit

A mobile application designed for pregnant women, providing features related to:

- Pregnancy-friendly exercise
- Nutrition
- Support and Q&A
- Personalized health-related content

Built using **Flutter** and connected to a backend system.
